# GitBot

A local-first AI assistant for GitHub repository maintenance, coding tasks,
contribution tracking, and safe development automation.

## Principles

- Genuine, useful software contributions.
- Local-first data storage.
- Explicit approval for consequential GitHub actions.
- Repository allowlisting and secret protection.
- Tested, incremental development.
